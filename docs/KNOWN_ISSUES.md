# Known Issues

## 1) 讯飞账号返回 `API error, code: 4001`
- 现象：自动采集时同平台部分账号成功、个别账号失败
- 常见原因：
  - 该账号 Cookie 过期或失效
  - 账号权限/套餐状态不满足接口访问
  - 账号会话被风控或已失效
- 影响：仅影响该账号采集，不影响其他账号
- 现有处理：
  - 记录 `last_collect_status=failed` 和 `last_collect_error`
  - 调度继续，不阻塞整轮
- 建议处理：
  - 重新配置该账号 Cookie
  - 后续可增加“连续失败计数 + 自动标记需重新登录”

## 2) Pydantic v2 兼容警告（Config 类写法）
- 现象：测试日志提示 class-based `config` 已弃用
- 影响：当前可运行，但后续升级有风险
- 建议：逐步迁移到 `ConfigDict`

## 3) 告警通知当前为基础版（日志 + 事件表）
- 现状：已支持阈值判定、冷却、防抖、恢复事件
- 缺口：尚未接入外部通知通道（Webhook/IM）
- 建议：P2-6 中补通道插件化
