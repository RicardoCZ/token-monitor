# 前端公共组件与脚本（Token Monitor）

本文汇总 `frontend/js/` 下可复用能力、推荐加载顺序与典型调用方式，便于新页面接入或让 AI 助手快速对齐现有约定。

---

## 1. 脚本加载顺序（务必遵守依赖）

### 一般子页（账号 / 规则 / 管理 / 历史 / 设置 等）

```
api-dashboard-state.js
→ api-dashboard-core.js
→ ui-shared.js
→ confirm-modal.js      （需要确认框、或需要 TMDAuth.logout 使用站内确认时）
→ dashboard-auth.js
→ （页面内联脚本）
```

**说明：** `TMDUi` 使用 `Object.assign` 合并导出，`confirm-modal.js` 可与 `ui-shared.js` 互换顺序，但须在 `dashboard-auth.js` 之前，这样退出登录会先走 `showConfirmModal`。

### 监控看板 `api.html`

```
api-dashboard-state.js
→ api-dashboard-core.js
→ ui-shared.js
→ confirm-modal.js
→ dashboard-auth.js
→ api-dashboard-app.js
```

### `setup.html` 特例

内联脚本开头会设置 `window.TMD.API_BASE`（本机端口或相对路径），须在**加载** `dashboard-auth.js` **之后**、**调用** `checkAuth` / `logout` 之前执行该赋值（当前页面已按此写法）。

## 2. `window.TMD`（`api-dashboard-state.js`）

全局状态容器，**非**工具函数集合。

| 字段 | 含义 |
|------|------|
| `API_BASE` | 默认 `location.origin`；设置页会被覆盖 |
| `CURRENT_PAGE` | 当前路径文件名小写（用于导航高亮/隐藏当前链） |
| `currentUser` | 最近一次鉴权成功后的用户对象（与 `GET /auth/me` 返回结构一致时由 `TMDAuth.checkAuth` 写入） |
| `authToken` | 与 `localStorage.token` 同步；请通过 `TMDAuth.syncTokenFromStorage()` 或 `getAuthHeaders()` 刷新 |
| `serviceRegistry` / `serviceDataCache` / `serviceAccountIds` | 监控看板专用 |
| `DASHBOARD_CACHE_KEY` | 监控看板 `sessionStorage` 缓存键名 |

---

## 3. `window.TMDCore`（`api-dashboard-core.js`）

依赖：必须先加载 `api-dashboard-state.js`。

**常用能力：** `escapeHtml`、`escapeAttr`、`extractApiErrorMessage`、`renderServiceIconHtml`、`normalizeMetricDefs`、`buildUsageNumbers`、`buildMetricRows`、`formatMetricValue`、`buildSparklineSvg`、`saveDashboardCache` / `loadDashboardCache`，以及告警摘要相关的 `formatDashboardAlertLine`、`alertEventEmoji` 等。

完整 API 以源码为准：`frontend/js/api-dashboard-core.js`。

页面内典型写法：

```javascript
const U = window.TMDCore;
const text = U.escapeHtml(userInput);
```

---

## 4. `window.TMDUi`（`ui-shared.js`）

依赖：`api-dashboard-state.js`、`api-dashboard-core.js` 已加载。

| 方法 | 作用 |
|------|------|
| `showToast(message, isError?, toastId?)` | 操作反馈；需要页面存在 `#toast` 及 `.toast` 样式（见下文） |
| `buildTopNavLinks(currentPageLower, { showAdminLink })` | 返回顶部导航 HTML 字符串 |
| `bindCustomSelectById(selectId, options?)` | 将原生 `<select>` 换成自定义下拉 |
| `bindCustomSelectElement(select, options?)` | 同上，传入 DOM 节点 |
| `refreshCustomSelect(selectId)` | 选项变更后刷新自定义下拉展示 |

`showConfirmModal` **不在**本文件，由 `confirm-modal.js` 合并进 `TMDUi`。

---

## 5. 确认弹窗 `showConfirmModal`（`confirm-modal.js`）

依赖：`ui-shared.js`（合并 `TMDUi`）。

首次调用会向 `document.head` 注入样式，向 `body` 挂载 `#tmd-confirm-modal-root`。**半透明压暗背景已按产品要求去掉**，遮罩为透明点击层，仅卡片有实色背景。

```javascript
const Ui = window.TMDUi;
if (!(await Ui.showConfirmModal({
  title: '删除',
  message: '确认删除吗？不可恢复。',
  confirmText: '删除',
  cancelText: '取消',
  danger: true,   // 主按钮红色
}))) return;
// 用户确认后继续
```

返回 `Promise<boolean>`：`true` 确认，`false` 为取消、点遮罩或 `Escape`。

## 6. `window.TMDAuth`（`dashboard-auth.js`）

依赖：`TMD`、`TMDCore`、`TMDUi`；退出确认需 `confirm-modal.js`（否则退回 `window.confirm`）。

| 方法 | 作用 |
|------|------|
| `syncTokenFromStorage()` | `localStorage.token` → `TMD.authToken`，返回 token 字符串或 `null` |
| `getAuthHeaders()` | `{ Authorization: 'Bearer …' }` |
| `getJsonHeaders()` | 在上式基础上加 `Content-Type: application/json` |
| `checkAuth(options?)` | `GET /auth/me`，写 `TMD.currentUser`，渲染 `#user-info`；失败跳转登录等 |
| `logout(options?)` | **先站内确认**（或 `confirm`），再 `POST /auth/logout`，清本地并跳转 `login.html` |
| `paintUserHeaderBar(user, options?)` | 仅渲染顶栏 |
| `readCachedUserFromLocalStorage()` | 读 `localStorage.user` 缓存 |

**`checkAuth` 常用选项：** `apiBase`、`requireAdmin`、`onNotAdmin`、`forceShowAdminLink`、`prefillHeaderFromCache`、`persistUserToLocalStorage: true`（设置页）、`onNetworkError`、`userInfoId`。

**`logout` 常用选项：** `apiBase`（与 `TMD.API_BASE` 不一致时）、`loginPath`、`skipConfirm: true`（仅自动化等特殊场景）、`onAfterClear`（如监控页清理 `sessionStorage` 看板缓存）。

服务端注销说明：JWT 带 `tv`（用户 `token_version`），`POST /auth/logout` 会递增版本，旧令牌失效。详见后端 `auth` 与安全模块。

---

## 7. Toast（`showToast` + 页面 DOM）

`TMDUi.showToast` 依赖：

```html
<div id="toast" class="toast"></div>
```

样式在各页面 `<style>` 中定义（`accounts` / `alerts` / `admin` 等）。提示在**视口上方**居中，带淡入淡出；`z-index` 低于确认弹窗，避免盖住模态。

---

## 8. 监控看板专用 `api-dashboard-app.js`

仅 `api.html` 在 `dashboard-auth` 之后加载。暴露 `window.TMDApp`、`refreshAll`、`logout`、`closeModal` 等。退出时应走 `TMDAuth.logout`（应用内已封装并清理看板 `sessionStorage`）。

---

## 9. 新页面最小清单（示例）

1. 引入第二节中的脚本链（按需含 `confirm-modal`）。  
2. `const S = window.TMD`，需要时覆盖 `S.API_BASE`。  
3. `const U = window.TMDCore`，`const Ui = window.TMDUi`，`const TMDAuth = window.TMDAuth`。  
4. 需要 Toast 时：`<div id="toast" class="toast">` + 从现有页复制 `.toast` 相关 CSS。  
5. 入口：`TMDAuth.checkAuth().then(ok => { if (ok) { … } })`。  
6. 危险操作：`await Ui.showConfirmModal(…)`。  
7. 顶栏「退出」：`onclick="logout()"` + `async function logout() { await TMDAuth.logout({ apiBase: S.API_BASE }); }`（多数页可省略 `apiBase`）。
