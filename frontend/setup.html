1 创建浏览器调试快捷方式：
① 找到你电脑上的 Chrome 或 Edge 快捷方式（开始菜单或桌面）
② 右键 → 属性 → 复制「目标」里的路径

④ 在路径最后加上参数：
--remote-debugging-port=9223 --remote-allow-origins=* --user-data-dir="C:\ChromeDebug"

3 在地址栏输入 chrome://inspect/#remote-debugging 并回车
✅ 勾选 Allow remote debugging for this browser instance
✅ 确认看到 Server running at: 127.0.0.1:9223（端口号可能不同）
4 回到本页面，填入端口号，点击连接
